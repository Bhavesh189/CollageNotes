## Notes on coverage decisions

- **Unit 3, Lecture 2 (cryptanalyst career material)** — the source lecture is largely career advice (what a cryptanalyst does, educational requirements, business applications). It is covered, condensed to the exam-relevant points (what cryptanalysis is, its types, cryptanalyst vs cryptographer vs cryptologist), not reproduced as full career guidance.
- **Garbled Kerberos diagram text (Unit 5)** — the source Kerberos diagram labels were OCR-garbled beyond recovery and were dropped; the Kerberos 6-step overview and the v4/v5 comparison were rewritten cleanly from the standard protocol, consistent with the source text.
- **CFB heading (Unit 2)** — the source prints the Cipher Feedback Mode heading as a garbled lowercase fragment (“r Feed Back Mode”), so the extractor missed it as a heading; its content sits inside the CBC section and is covered there, and CFB has its own full expansion and 70Q/solutions coverage.
- **Row transposition worked example (Unit 1)** — the source prints a wrong ciphertext (“ESOTCUEEHMHLAHSTOETO”). It was recomputed by hand and the corrected value is used: key 4312567, rows MEETATT / HESCHOO / LHOUSE, columns in order 4, 3, 1, 2, 5, 6, 7 gives **TCUESOMHLEEHAHSTOETO**.
- **Unit 2 header vs body** — the Unit 2 header mentions “location of encryption devices, key distribution, message authentication, secure hash functions and HMAC”, but the body does not cover them; those topics are covered in Units 4 and 5 where the source actually teaches them.
- **Unit 4 image-only pages (pp 10, 13, 20)** — figures/tables that exist only as images in the source (including the SHA comparison table) are reproduced as drawn diagrams/tables in the notes using standard values (SHA-1: 160/512/80; SHA-256: 256/512/64; SHA-384: 384/1024/80; SHA-512: 512/1024/80).
- **X.509 field list and Kerberos steps (Unit 5)** — rewritten cleanly from standard knowledge consistent with the source, because the source’s own lists were fragmented; “Knohnfelder” in the source is a misspelling of Kohnfelder.
