# Handwritten Notes (Full Depth)

Complete handwritten-style notes for every subject in this repository, Sem 1–8, built from the source notes in `notes-source/` (plus syllabus / PYQ topics where no source notes existed).

- **84 subjects — 11,875 pages of notes** (`sem1/` … `sem8/`)
- **301 PYQ solution PDFs — 5,154 pages** (`pyq-solutions/sem1/` … `pyq-solutions/sem8/`), one per paper in `public/pyq/`
- Every notes PDF has Units 1–5 (Sem 8 FHI has 7 units) + **70 Most Important Questions** from that subject's PYQs (repeated questions starred ★)
- Style: Patrick Hand font, blue body ink, black underlined headings, red key terms, unlined white A4, ~1.5 cm margins, unit name on top of every page, page number at the bottom

## Layout

```
handwritten-notes/
  sem1/ … sem8/        one *-Handwritten-Notes-Full.pdf per subject
                        + *-coverage-check.md (topic-by-topic coverage checklist)
                        + PROGRESS-semN.md
  pyq-solutions/
    sem1/ … sem8/      one *-solution.pdf per PYQ paper (question in handwriting
                        first, then the full answer; unclear/illegible questions
                        are flagged inside the PDF, never guessed)
```
